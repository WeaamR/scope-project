# n8n Workflow Exports

The JSON files in `exports-review-only/` are sanitized copies of the three exports supplied for SCOPE documentation. They are included for inspection and documentation, not as verified import-ready production workflows.

Before importing or publishing them, compare the connections with the live n8n workflows and reconnect any missing nodes. Credential IDs, webhook IDs, internal instance IDs, and the Supabase publishable-key value have been redacted. Reconfigure credentials securely in n8n after import if you choose to use these files.
